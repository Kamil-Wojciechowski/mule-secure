Mule Secure Properties Tool

A browser-based port of MuleSoft's secure-properties-tool CLI.

Runs entirely in your browser. Your key and value are never sent anywhere — there is no server, no analytics, no network calls after the page loads. You can disconnect from the internet and it will keep working.

This is an unofficial, independently-verified reimplementation and is not affiliated with or endorsed by MuleSoft or Salesforce. It supports the CLI tool's string and file modes (not file-level). See the README for how its output was validated against the real jar.
